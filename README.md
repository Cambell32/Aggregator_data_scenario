Repository contains all the files related to the Aggregator Data Scenario and includes: 

The original ABS excel and data scenario files 

The Python files that were used to generate and handle the data via MYSQL database before it was transformed into CSV files for Power BI.

A MYSQL schema file of the aggre_db. 

The CSV files that were generated, inserted, and retrieved from a MYSQL xampp installation database. 

The Power BI report that contains all of the visualizations and relationships between the utilized CSV files. 

The Power Point slide deck to consolidate and present the aggregate data.
